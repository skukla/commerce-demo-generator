# Canonical Data Format

The canonical format is a platform-neutral representation of catalog data. Both Commerce and ACO datapacks are generated by transforming from this canonical format.

## Architecture

```
Product Definitions → Canonical Format (JSON)
                           ↓           ↓
                  generate-commerce  generate-aco
                           ↓           ↓
                   Commerce JSON    ACO JSON
```

## Benefits

1. **Single Source of Truth**: One canonical format, multiple output formats
2. **Platform Agnostic**: No format is "privileged" over another
3. **Maintainability**: Changes to one platform don't affect transformations to another
4. **Extensibility**: Easy to add new platforms (Shopify, BigCommerce, etc.)
5. **Testability**: Can validate canonical format independently

## Field Mapping

### Status Mapping

| Canonical | Commerce | ACO |
|-----------|----------|-----|
| enabled | 1 | ENABLED |
| disabled | 2 | DISABLED |

### Visibility Mapping

| Canonical | Commerce | ACO visibleIn |
|-----------|----------|---------------|
| not_visible | 1 | [] |
| catalog | 2 | ["CATALOG"] |
| search | 3 | ["SEARCH"] |
| catalog_search | 4 | ["CATALOG", "SEARCH"] |

### Product Type Mapping

| Canonical | Commerce | ACO Handling |
|-----------|----------|--------------|
| simple | simple | SimpleProductView |
| configurable | configurable | ComplexProductView + variants with links |
| bundle | bundle | Not yet supported |

## Transformation Rules

### Commerce Transform
- Map canonical attributes to Commerce CSV columns
- Handle image paths for Commerce format
- Convert category slugs to category paths
- Apply Commerce-specific defaults

### ACO Transform
- Map canonical attributes to ACO attributes array
- Create links array for variant relationships
- Create configurations array for configurable products
- Generate routes from category slugs
- Apply ACO-specific field requirements

## Implementation Files

- `generators/generate-canonical.js` - Main generator (replaces generate-commerce.js step 1)
- `generators/generate-commerce.js` - Transform canonical → Commerce
- `generators/generate-aco.js` - Transform canonical → ACO
- `config/canonical-schema.json` - JSON Schema for validation (optional)
