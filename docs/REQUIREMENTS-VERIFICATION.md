### Format Transformations

#### 1.1 Products Format

**Requirement:** Transform Commerce ACCS format → ACO format

**Documented Requirements:**
- ❌ No `source` wrapper in ACO
- ❌ Attributes as array of objects (not flat)
- ❌ `visibility` (number) → `visibleIn` (array)
- ❌ `url_key` → `slug`
- ❌ Categories excluded (ACO doesn't manage them)
- ✅ Custom attributes use project's `attributePrefix`

**Implementation Check:**

```javascript
// generate-aco.js lines 41-95
function transformToAcoProduct(commerceProduct) {
  const acoProduct = {
    sku: commerceProduct.sku,                    // ✅ Direct mapping
    source: { locale: 'en-US' },                 // ✅ ACO format
    name: commerceProduct.name,                   // ✅ Direct mapping
    slug: commerceProduct.url_key,                // ✅ url_key → slug
    description: commerceProduct.description,     // ✅ Direct mapping
    status: commerceProduct.product_online === 1 ? 'ENABLED' : 'DISABLED',  // ✅ Transform
    visibleIn: mapVisibility(commerceProduct.visibility)  // ✅ Number → array
  };
  
  // ✅ Attributes as array of objects
  acoProduct.attributes = [];
  const attributePrefix = PROJECT_CONFIG.project.attributePrefix;  // ✅ Dynamic prefix
  
  for (const [key, value] of Object.entries(commerceProduct)) {
    if (key.startsWith(attributePrefix) && value !== null && value !== '') {
      acoProduct.attributes.push({
        code: key,
        values: Array.isArray(value) ? value : [value]
      });
    }
  }
  
  return acoProduct;
}
```

**Result:** ✅ PASS - All transformation requirements met

**Impact:** ACO may not properly understand variant relationships

**Recommendation:** Create dedicated variant transformation:
```javascript
function transformToAcoVariant(commerceVariant) {
  const selections = {};
  if (commerceVariant.configurable_variations) {
    commerceVariant.configurable_variations.split(',').forEach(pair => {
      const [key, value] = pair.split('=');
      selections[key.trim()] = value.trim();
    });
  }
  
  return {
    ...transformToAcoProduct(commerceVariant),
    parentSku: commerceVariant.parent_sku,
    selections
  };
}
```
